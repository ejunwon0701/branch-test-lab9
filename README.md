# Week 9: Remote Branch and Collaboration

This public repository records the Week 9 Git collaboration practice.

## Practice completed

- Created and tracked a remote branch (`local-hotfix`)
- Made different edits on `main` and `local-hotfix`
- Created a pull request with a merge conflict
- Resolved the conflict by keeping both changes
- Merged the pull request into `main`
- Added later local and remote update commits

## Useful commands

```bash
git remote -v
git branch -a
git fetch origin
git pull origin main
git push -u origin <branch-name>
```

## Privacy

Only practice data is included. Secret files, environment files, and private keys are excluded by `.gitignore`.
